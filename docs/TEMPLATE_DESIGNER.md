# Visual template designer

The three-panel flow editor provides component/layer controls, physical paper canvas, zoom and a properties inspector. Authors can click or drag components onto the canvas, reorder top-level elements, select with Shift, group/ungroup, lock, duplicate, delete, move layers, set fonts/borders/alignment/sizes, bind approved fields, add conditions/repeating item children, and publish/export.

Keyboard shortcuts: Ctrl/Cmd+Z undo, Shift+Ctrl/Cmd+Z redo, Ctrl/Cmd+C/V internal node clipboard, Ctrl/Cmd+A top-level selection, Delete unlocked selection. Focusable canvas elements also select with Enter/Space. Draft changes save after a debounce and do not replace published automation templates.

The editing canvas shows bindings and structural guides. Preview invokes the actual renderer and displays its PNG pages/PDF export; the editable sketch is not advertised as pixel-identical print output.

Absolute positioning, resize handles, proper physical rulers, snap/alignment guides, page-master headers/footers, asset library, reusable blocks, robust nested regroup/reorder and full clipboard interoperability remain incomplete. The current ruler is illustrative; numeric dimensions are authoritative. Publication should be reviewed in actual preview before automatic assignment.
