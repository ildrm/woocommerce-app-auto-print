# Fictional print fixtures

`scripts/integration-check.py` generates the files in rendered/ through the real authenticated agent/renderer. They contain explicitly fictional customer details and sample order 1001; no source photograph's personal/payment information is used.

PDF and PNG language samples are evidence of the common rendering path. They are not physical printer output or approved linguistic golden baselines. Regenerate after renderer/font/template changes, inspect for shaping/ordering/clipping, and record reviewed references separately before enabling visual regression gating.
